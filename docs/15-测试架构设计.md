# CampusPilot 测试架构设计

## 一、测试概述

### 1.1 测试目标
CampusPilot测试架构旨在确保系统质量，包括功能正确性、性能稳定性、安全性可靠性等。

### 1.2 测试原则
1. **测试金字塔**：单元测试 > 集成测试 > E2E测试
2. **自动化优先**：尽可能自动化测试
3. **持续测试**：测试集成到CI/CD流程
4. **测试覆盖**：关键代码测试覆盖率 > 80%
5. **测试数据**：使用真实场景的测试数据

## 二、测试层次

### 2.1 测试金字塔

```
        /\
       /  \  E2E测试 (10%)
      /----\
     /      \  集成测试 (20%)
    /--------\
   /          \  单元测试 (70%)
  /------------\
```

### 2.2 测试类型

#### 单元测试
- **目标**：测试单个方法或类
- **范围**：Service层、Mapper层、工具类
- **工具**：JUnit 5、Mockito
- **覆盖率**：> 80%

#### 集成测试
- **目标**：测试模块间交互
- **范围**：Controller层、Service间调用
- **工具**：Spring Boot Test、TestContainers
- **覆盖率**：> 70%

#### E2E测试
- **目标**：测试完整业务流程
- **范围**：用户登录、政策查询、任务创建
- **工具**：Selenium、Cypress
- **覆盖率**：核心流程100%

### 6.3 性能测试场景

```java
@SpringBootTest
@ActiveProfiles("test")
class PerformanceTest {
    
    @Autowired
    private MockMvc mockMvc;
    
    @Test
    void testLoginPerformance() throws Exception {
        int totalRequests = 1000;
        int concurrentUsers = 100;
        
        ExecutorService executor = Executors.newFixedThreadPool(concurrentUsers);
        List<Future<Long>> futures = new ArrayList<>();
        
        long startTime = System.currentTimeMillis();
        
        for (int i = 0; i < totalRequests; i++) {
            futures.add(executor.submit(() -> {
                long requestStart = System.currentTimeMillis();
                
                LoginRequest request = new LoginRequest();
                request.setUsername("2021001");
                request.setPassword("password");
                
                mockMvc.perform(post("/api/auth/login")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content(new ObjectMapper().writeValueAsString(request)))
                    .andExpect(status().isOk());
                
                return System.currentTimeMillis() - requestStart;
            }));
        }
        
        // 收集结果
        List<Long> responseTimes = new ArrayList<>();
        for (Future<Long> future : futures) {
            responseTimes.add(future.get());
        }
        
        long totalTime = System.currentTimeMillis() - startTime;
        
        // 计算指标
        double averageResponseTime = responseTimes.stream()
            .mapToLong(Long::longValue)
            .average()
            .orElse(0.0);
        
        double throughput = (double) totalRequests / (totalTime / 1000.0);
        
        System.out.println("Total Requests: " + totalRequests);
        System.out.println("Average Response Time: " + averageResponseTime + "ms");
        System.out.println("Throughput: " + throughput + " requests/second");
        
        executor.shutdown();
    }
}
```
