# CampusPilot 高校校园学生事务智能体

## 一、项目介绍

CampusPilot是一个面向高校学生的AI智能事务办理系统，旨在解决校园服务中信息分散、流程复杂、办理困难等痛点问题。系统基于大语言模型、RAG检索增强生成、Agent智能体等先进技术，构建了一个从"问得到"到"办得到"的校园事务智能服务平台。

传统校园服务主要解决"学生去哪里问"的问题，而CampusPilot要解决的是"学生只需要告诉AI自己想办什么，AI自动理解需求、查询校园政策、判断办理条件、规划办理流程、调用校园业务工具、创建待办并持续跟踪"的全流程服务问题。

## 二、核心功能

### 1. 智能政策咨询
- 基于RAG的校园政策知识库检索
- 政策版本识别与时效判断
- 多轮对话上下文理解
- 政策来源引用与准确性保障

### 2. 事务资格判断
- 自动获取学生信息与成绩数据
- 多维度条件匹配与资格校验
- 缺失条件识别与材料清单生成
- 个性化申请建议

### 3. 事务办理执行
- 自然语言事务办理请求解析
- 多步骤Workflow自动编排
- 工具调用与业务系统集成
- 待办创建与进度跟踪

### 4. 主动校园服务
- 截止日期智能监控
- 未完成事项主动提醒
- 学生事务状态跟踪
- 个性化服务推送

### 5. 复杂度自适应
- 简单问题：RAG问答模式
- 复杂问题：多工具协作模式
- 任务问题：Workflow执行模式
- 动态选择最优处理策略

## 五、创新性

### 1. 从问答到执行
传统AI校园助手只能提供信息查询，CampusPilot实现了事务的完整执行流程，真正解决了"知道但办不到"的校园服务痛点。

### 2. 复杂度自适应Agent
系统能够根据用户问题的复杂程度自动选择最优处理策略，简单问题快速回答，复杂问题深入处理，任务问题自动执行。

### 3. 主动校园服务
突破传统被动问答模式，系统能够主动发现学生需要处理的事务，提前进行提醒和干预，实现从"学生找服务"到"服务找学生"的转变。

### 4. 政策时效感知
Agent能够识别和区分不同版本的政策，优先使用当前有效政策，避免因政策过期导致的错误指导。

### 5. 真正的Agent能力
不是简单的聊天机器人，而是具备理解、检索、判断、规划、工具调用、执行、任务跟踪、主动提醒完整能力的智能体系统。
