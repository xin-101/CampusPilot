# 答辩 Q&A 准备

> 以下为按照实现真实情况准备的预期提问与回答口径。所有数字均来自 `evaluation/results/`，
> 演示见 `docs/24-比赛Demo脚本.md`。

## 1. 系统的核心功能是什么？
面向校园的智能体：学生用自然语言完成**政策咨询、资格判断、申请办理、进度查看**，
系统主动**提醒**截止时间，并对越权/隐私类请求做**安全拦截**。辅导员/管理员可通过角色账号
查看任务与政策（RBAC）。FastGPT 接入后无缝切换为大模型驱动，未接入时本地引擎提供服务但诚实声明。

## 2. 资格判断为什么不用大模型？——模型的"确定性问题"信任问题
资格结论影响学生切身利益（能否申奖学金/助学金），需要**可审计、可复现**。
规则引擎从 `eligibility_rules` 取真实规则（条件/操作符/值），对数据库中学生真实数据计算，
结论可解释；LLM 只负责对话与语义理解，避免幻觉导致错误结论。演示：两次问同一句话，答案一致，轨迹面板可见每一步。

## 3. 大模型（FastGPT）没接，能算数吗？
诚实优先。系统设计为**提供方可插拔**：dev/mock 用本地可运行提供方做全链路与评测；
prod 用 SF-FastGPT。当前环境无 FastGPT，返回 `WAITING_FOR_FASTGPT_ENVIRONMENT` 明确声明，
**绝不伪造**。接口、安全守卫、RAG、规则引擎、任务链路在两种提供方下完全一致，
接入只需按 `docs/23-FastGPT联调清单.md` 填配置并实现客户端真实调用。

## 4. 检索结果怎么保证相关？（RAG 命中率怎么来的）
双保险：`VectorPolicyRetriever`（本地 TF-IDF+中文 bigram 向量，**最低相关阈值 0.05**，
`finalScore=0.75·cosine+0.25·keywordBoost`，低相关文档剔除）+ 关键词策略兜底。
评测数据来自 `evaluation/rag/cases.json`，`run-rag-eval.mjs` 用真实 HTTP 按组路由
（纯检索走 `/api/rag/retrieve`，问答走 `/api/agent/chat`），16/16 = 100%。

## 5. 知识库文档和数据库政策是两套数据，怎么保证一致？
这就是"双库对齐"创新点（`docs/25-创新点.md` 第 1 条）：`resolveDbPolicyIdByName`
用标题最长公共子串（LCS≥6）把知识检索命中文档**回映射**到 DB 政策，资格判断与建任务都基于它，
既解决规则错配，也让 `tasks.policy_id` 外键合法。

## 6. 安全怎么做的？能防哪些攻击？
`AgentSecurityGuard` 四类拦截：身份越权、管理员冒充、工具注入、提示词泄露；
隐私关键词 × 他人身份配对检测；服务端所有权校验（学生只能碰自己的任务）。
Phase4 M4 安全用例 4/4 拦截，Phase3 安全回归 4/4。日志不打印 JWT/密码/API Key。

## 7. 性能怎么样？
Phase4 M6 用真实请求采样：p50≈665ms、p95≈995ms、max≈1042ms，预算 1500ms 内达标。
（FastGPT 接入后需重新测评。）

## 8. 部署方式？
`docker-compose.yml`：mysql + backend + frontend 三服务，`database/init.sql` 自动建库建表种子。
本地开发可选 `scripts/start-dev.ps1`。已做容器编排与部署说明（`docs/16-部署架构设计.md`）。

## 9. 数据都是真的吗？
政策/资格为 **DEMO 数据（`is_demo=1`）**，聊天与页面带免责声明；但**链路真实**：
任务/通知真实落库 MySQL，规则从表加载，评测为真实 HTTP。从不把演示数据包装成真实校规。

## 10. 和别的"校园客服机器人"区别？
不止问答：主动提醒 + 可审计规则判断 + 任务闭环 + 安全硬边界 + 实评测体系（90+ 断言一键复跑）。
评测不是截图，是由脚本在真实后端上跑出来的可复现指标（`scripts/run-evaluation.ps1`）。

## 11. 有哪些模块、代码量级？
后端 Spring Boot 3.2 分模块：agent（提供方/意图/安全/执行轨迹）、eligibility 规则引擎、
workflow 编排、notification 提醒、rag 检索、task/policy/auth 业务 + 前端 Vue3 管理台与聊天面板 +
8 类政策知识库 + 三套评测。模块清单见 `docs/04-智能体设计说明书.md` 与 Phase 自检报告。
