# 创新点说明

CampusPilot 面向校园场景的智能体平台，核心创新点如下，均以真实代码与真实运行数据支撑。

## 1. RAG 检索：知识库文档 → 数据库政策 的"双库对齐"（V3 亮点）

- **问题**：知识库 `knowledge/*.json` 与 `policies` 表是**两套数据**（8 分类知识条目 policyId=10000+index，
  任务表 `tasks.policy_id` 又有外键指向 `policies(id)`）。直接拿知识条目做资格判断/建任务会
  规则错配（category 级兜底）或外键失败。
- **方案**：`PolicyService.resolveDbPolicyIdByName(policyName, category)` 用标题 **最长公共子串（LCS ≥ 6 字符）**
  把检索命中的知识文档**回映射**到 DB 政策；`EligibilityCheckServiceImpl` 与 `TaskCreationWorkflow` 均基于它，
  命中全局一致、建任务合法。
- **效果**：资格判断从"按分类兜底（可能把励志的困难规则误用到奖学金）"升级为"按政策精确定位规则"，
  回归用例：张三（国家奖学金）ELIGIBLE、李四（励志/助学金）ELIGIBLE，任务 `policyId` 正确落库。

## 2. 本地可自证向量检索：TF-IDF + 中文 bigram，无需外部 Embedding 服务

- 无外部 Embedding 环境也能**真实**向量化：标题+正文做中文 bigram 分词 + TF-IDF，构造向量。
- `VectorPolicyRetriever` 引入最低相关阈值 0.05，`finalScore = 0.75·cosine + 0.25·keywordBoost`，
  零分/低相关文档被剔除（计数器 `filteredLowScore` 入执行轨迹），让"检索到但毫无相关"的假命中不再污染答案。
- RAG 评测 `evaluation/rag` **16/16 (100%)** 全绿，每条截图可复现。

## 3. 可审计的资格规则引擎（不靠大模型猜结论）

- 资格判断走**本地规则引擎**（`eligibility_rules` 表：条件类型/操作符/值），从真实学生数据计算，
  结论可审计、可复现、**不产生 LLM 幻觉**；大模型（FastGPT）仅负责对话与语义，资格结论以规则为准并保留免责声明。

## 4. 安全守卫与可信执行（硬边界）

- `AgentSecurityGuard` 前置四类拦截：**身份越权**（查他人成绩/隐私）、**管理员冒充**、
  **工具注入**、**提示词泄露**，全部 `DENIED` 且不执行任何工具。
- 隐私关键词 × 他人身份模式**配对**检测（成绩/绩点/密码/银行卡/身份证… × 张三/李四/2021001…）。
- 日志与错误脱敏：不打印 JWT/密码/API Key/Authorization；MyBatis SQL stdout 日志已关停；
  前端错误不回流原始堆栈（`BusinessException` 固定文案）。
- 安全评测四连发（M4）**100% 拦截**；Phase3 安全回归 4/4。

## 5. 最小可信的本地"自给"链路（国内/校园环境可用）

- 无云资源时：`MockAgentProvider`（可运行、可评测、诚实声明）+ 本地 TF-IDF 向量 + 规则引擎 + MySQL，
  全链路真实可复现；配置了 SF-FastGPT 后切换到 `FastGPTProvider`（未配置绝不伪造，返回
  `WAITING_FOR_FASTGPT_ENVIRONMENT`）。
- 评测体系与实现解耦：`evaluation/phase3|phase4|rag` 三套真实 HTTP 评测（共 90+ 断言），
  `scripts/run-evaluation.ps1` 一键复跑。

## 6. 主动服务而非被动问答

- 到点提醒 + 逾期提醒双通路（`ReminderServiceImpl`），每分钟调度、**幂等发送**（`reminder_sent=1`），
  把"学生错过截止"变成系统主动触达（Demo4 自动化验证 REMINDER 通知真实生成）。
- 从「咨询 → 判断 → 办理 → 提醒 → 安全」形成完整闭环，附带执行轨迹 `ExecutionTrace` 全链路可溯源。

## 7. 三账号真实 RBAC 演示

- `demo_student / demo_counselor / demo_admin`（BCrypt，真实登录）覆盖学生/辅导员/管理员三视角，
  角色边界与数据所有权校验（`fetchTaskWithOwnershipCheck`）真实生效。
