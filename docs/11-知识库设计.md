# CampusPilot 知识库设计

## 一、知识库概述

### 1.1 设计目标
CampusPilot知识库用于存储和管理校园政策文档，支持RAG检索和智能问答。知识库需要：
- 支持多类型政策文档存储
- 支持政策版本管理
- 支持语义检索
- 支持元数据过滤
- 支持引用来源

### 1.2 设计原则
1. **结构化存储**：政策文档结构化存储，便于检索
2. **版本管理**：支持政策多版本管理
3. **时效控制**：支持政策生效时间和失效时间
4. **分类管理**：按政策类型分类管理
5. **元数据丰富**：丰富的元数据支持精准检索

## 四、文档切分策略

### 4.1 切分原则
1. **语义完整**：保持语义完整性
2. **长度适中**：每个切片500-1000字
3. **重叠处理**：相邻切片有一定重叠
4. **元数据保留**：保留文档结构信息

### 4.2 切分算法

```java
@Service
public class DocumentSplitter {
    
    private static final int MAX_CHUNK_SIZE = 1000;
    private static final int MIN_CHUNK_SIZE = 100;
    private static final int OVERLAP_SIZE = 100;
    
    public List<DocumentChunk> split(String document, PolicyMetadata metadata) {
        List<DocumentChunk> chunks = new ArrayList<>();
        
        // 1. 按标题切分
        String[] sections = splitByHeaders(document);
        
        for (int i = 0; i < sections.length; i++) {
            String section = sections[i];
            
            // 2. 如果章节太长，进一步切分
            if (section.length() > MAX_CHUNK_SIZE) {
                chunks.addAll(splitLongSection(section, metadata, i));
            } else if (section.length() >= MIN_CHUNK_SIZE) {
                chunks.add(createChunk(section, metadata, i, sections.length));
            }
        }
        
        return chunks;
    }
    
    private String[] splitByHeaders(String document) {
        // 按标题切分
        return document.split("(?=^#\\s)");
    }
    
    private List<DocumentChunk> splitLongSection(String section, PolicyMetadata metadata, int sectionIndex) {
        List<DocumentChunk> chunks = new ArrayList<>();
        
        // 按句子切分
        String[] sentences = section.split("(?<=[。！？])");
        
        StringBuilder currentChunk = new StringBuilder();
        int chunkIndex = 0;
        
        for (String sentence : sentences) {
            if (currentChunk.length() + sentence.length() > MAX_CHUNK_SIZE) {
                if (currentChunk.length() >= MIN_CHUNK_SIZE) {
                    chunks.add(createChunk(
                        currentChunk.toString(), 
                        metadata, 
                        sectionIndex, 
                        chunkIndex++
                    ));
                }
                currentChunk = new StringBuilder();
                
                // 添加重叠
                if (chunks.size() > 0) {
                    String lastChunk = chunks.get(chunks.size() - 1).getContent();
                    if (lastChunk.length() > OVERLAP_SIZE) {
                        currentChunk.append(lastChunk.substring(lastChunk.length() - OVERLAP_SIZE));
                    }
                }
            }
            currentChunk.append(sentence);
        }
        
        if (currentChunk.length() >= MIN_CHUNK_SIZE) {
            chunks.add(createChunk(
                currentChunk.toString(), 
                metadata, 
                sectionIndex, 
                chunkIndex
            ));
        }
        
        return chunks;
    }
    
    private DocumentChunk createChunk(String content, PolicyMetadata metadata, int sectionIndex, int chunkIndex) {
        return DocumentChunk.builder()
            .id(metadata.getPolicyId() + "_s" + sectionIndex + "_c" + chunkIndex)
            .content(content.trim())
            .metadata(DocumentChunkMetadata.builder()
                .policyId(metadata.getPolicyId())
                .title(metadata.getTitle())
                .chunkIndex(chunkIndex)
                .keywords(extractKeywords(content))
                .build())
            .build();
    }
    
    private List<String> extractKeywords(String content) {
        // 提取关键词
        List<String> keywords = new ArrayList<>();
        
        // 简单的关键词提取
        String[] importantWords = {"申请", "条件", "材料", "流程", "时间", "截止", "要求"};
        for (String word : importantWords) {
            if (content.contains(word)) {
                keywords.add(word);
            }
        }
        
        return keywords;
    }
}
```

### 5.2 Query Rewrite

```java
@Service
public class QueryRewriter {
    
    @Autowired
    private LLMService llmService;
    
    public String rewrite(String originalQuery) {
        // 1. 同义词扩展
        String expandedQuery = expandSynonyms(originalQuery);
        
        // 2. 查询改写
        String rewrittenQuery = llmService.rewriteQuery(originalQuery);
        
        // 3. 查询合并
        return mergeQueries(originalQuery, expandedQuery, rewrittenQuery);
    }
    
    private String expandSynonyms(String query) {
        Map<String, List<String>> synonyms = Map.of(
            "奖学金", Arrays.asList("助学金", "奖励", "资助"),
            "申请", Arrays.asList("办理", "提交", "申领"),
            "条件", Arrays.asList("要求", "资格", "标准"),
            "材料", Arrays.asList("文件", "证明", "文档")
        );
        
        StringBuilder expanded = new StringBuilder(query);
        for (Map.Entry<String, List<String>> entry : synonyms.entrySet()) {
            if (query.contains(entry.getKey())) {
                for (String synonym : entry.getValue()) {
                    expanded.append(" ").append(synonym);
                }
            }
        }
        
        return expanded.toString();
    }
}
```

### 5.5 Rerank

```java
@Service
public class Reranker {
    
    @Autowired
    private LLMService llmService;
    
    public List<SearchResult> rerank(String query, List<SearchResult> results) {
        // 1. 计算相关性分数
        List<ScoredResult> scoredResults = results.stream()
            .map(result -> {
                double score = calculateRelevance(query, result);
                return new ScoredResult(result, score);
            })
            .sorted(Comparator.comparingDouble(ScoredResult::getScore).reversed())
            .collect(Collectors.toList());
        
        // 2. 去重
        List<SearchResult> deduplicated = deduplicate(scoredResults);
        
        // 3. 返回Top-K
        return deduplicated.stream()
            .limit(5)
            .collect(Collectors.toList());
    }
    
    private double calculateRelevance(String query, SearchResult result) {
        // 语义相似度 + 关键词匹配 + 政策时效性
        double semanticScore = llmService.calculateSimilarity(query, result.getContent());
        double keywordScore = calculateKeywordMatch(query, result.getContent());
        double timelinessScore = calculateTimeliness(result.getEffectiveDate());
        
        return semanticScore * 0.6 + keywordScore * 0.3 + timelinessScore * 0.1;
    }
}
```

```java
@Service
public class PolicyVersionManager {
    
    @Autowired
    private PolicyMapper policyMapper;
    
    @Autowired
    private PolicyVersionMapper versionMapper;
    
    /**
     * 获取当前有效版本
     */
    public PolicyVersion getActiveVersion(Long policyId) {
        return versionMapper.selectOne(
            new LambdaQueryWrapper<PolicyVersion>()
                .eq(PolicyVersion::getPolicyId, policyId)
                .eq(PolicyVersion::getStatus, "ACTIVE")
                .le(PolicyVersion::getEffectiveDate, LocalDate.now())
                .ge(PolicyVersion::getExpiryDate, LocalDate.now())
                .orderByDesc(PolicyVersion::getVersion)
                .last("LIMIT 1")
        );
    }
    
    /**
     * 获取所有版本
     */
    public List<PolicyVersion> getAllVersions(Long policyId) {
        return versionMapper.selectList(
            new LambdaQueryWrapper<PolicyVersion>()
                .eq(PolicyVersion::getPolicyId, policyId)
                .orderByDesc(PolicyVersion::getVersion)
        );
    }
    
    /**
     * 检查政策是否有效
     */
    public boolean isActive(Long policyId) {
        PolicyVersion version = getActiveVersion(policyId);
        return version != null;
    }
    
    /**
     * 添加新版本
     */
    public void addVersion(Long policyId, String version, String content, LocalDate effectiveDate, LocalDate expiryDate) {
        // 将旧版本设为失效
        versionMapper.update(null,
            new LambdaUpdateWrapper<PolicyVersion>()
                .eq(PolicyVersion::getPolicyId, policyId)
                .eq(PolicyVersion::getStatus, "ACTIVE")
                .set(PolicyVersion::getStatus, "INACTIVE")
        );
        
        // 添加新版本
        PolicyVersion newVersion = PolicyVersion.builder()
            .policyId(policyId)
            .version(version)
            .content(content)
            .effectiveDate(effectiveDate)
            .expiryDate(expiryDate)
            .status("ACTIVE")
            .build();
        
        versionMapper.insert(newVersion);
    }
}
```

### 6.2 版本检索策略

```java
@Service
public class PolicySearchStrategy {
    
    @Autowired
    private PolicyVersionManager versionManager;
    
    public List<PolicyVersion> searchVersions(String query, Map<String, Object> filters) {
        // 1. 获取所有有效版本
        List<PolicyVersion> allVersions = getAllActiveVersions();
        
        // 2. 应用过滤器
        List<PolicyVersion> filteredVersions = applyFilters(allVersions, filters);
        
        // 3. 语义检索
        List<PolicyVersion> semanticResults = semanticSearch(query, filteredVersions);
        
        return semanticResults;
    }
    
    private List<PolicyVersion> getAllActiveVersions() {
        return versionMapper.selectList(
            new LambdaQueryWrapper<PolicyVersion>()
                .eq(PolicyVersion::getStatus, "ACTIVE")
                .le(PolicyVersion::getEffectiveDate, LocalDate.now())
                .ge(PolicyVersion::getExpiryDate, LocalDate.now())
        );
    }
    
    private List<PolicyVersion> applyFilters(List<PolicyVersion> versions, Map<String, Object> filters) {
        return versions.stream()
            .filter(version -> {
                if (filters.containsKey("category")) {
                    // 获取政策分类
                    Policy policy = policyMapper.selectById(version.getPolicyId());
                    if (!policy.getCategory().equals(filters.get("category"))) {
                        return false;
                    }
                }
                return true;
            })
            .collect(Collectors.toList());
    }
}
```

## 八、冲突政策处理

### 8.1 冲突检测

```java
@Service
public class PolicyConflictDetector {
    
    public List<PolicyConflict> detectConflicts(List<PolicyVersion> versions) {
        List<PolicyConflict> conflicts = new ArrayList<>();
        
        // 按政策分类分组
        Map<String, List<PolicyVersion>> groupedVersions = versions.stream()
            .collect(Collectors.groupingBy(this::getPolicyCategory));
        
        for (Map.Entry<String, List<PolicyVersion>> entry : groupedVersions.entrySet()) {
            String category = entry.getKey();
            List<PolicyVersion> categoryVersions = entry.getValue();
            
            // 检测冲突
            for (int i = 0; i < categoryVersions.size(); i++) {
                for (int j = i + 1; j < categoryVersions.size(); j++) {
                    PolicyConflict conflict = checkConflict(
                        categoryVersions.get(i), 
                        categoryVersions.get(j)
                    );
                    if (conflict != null) {
                        conflicts.add(conflict);
                    }
                }
            }
        }
        
        return conflicts;
    }
    
    private PolicyConflict checkConflict(PolicyVersion v1, PolicyVersion v2) {
        // 检查时间重叠
        if (isTimeOverlapping(v1, v2)) {
            return PolicyConflict.builder()
                .policy1(v1)
                .policy2(v2)
                .conflictType("TIME_OVERLAP")
                .description("两个政策存在时间重叠")
                .build();
        }
        
        return null;
    }
}
```

```java
    private List<PolicyVersion> getChangedVersions(LocalDate since) {
        return versionMapper.selectList(
            new LambdaQueryWrapper<PolicyVersion>()
                .ge(PolicyVersion::getUpdatedAt, since)
        );
    }
    
    private void updateChunks(PolicyVersion version) {
        // 删除旧切片
        fastGPTClient.deleteChunksByPolicyId(version.getPolicyId().toString());
        
        // 添加新切片
        List<DocumentChunk> chunks = splitter.split(
            version.getContent(), 
            buildMetadata(version)
        );
        fastGPTClient.addChunks(chunks);
    }
}
```
