# CampusPilot 总体技术架构

## 一、架构概述

### 1.1 架构目标
CampusPilot采用分层架构设计，实现前后端分离、Agent与业务解耦、模块化开发的目标。架构需要支持：
- 高可扩展性：支持功能模块的灵活扩展
- 高可维护性：代码结构清晰，易于维护
- 高可用性：系统稳定可靠，故障自动恢复
- 高性能：响应速度快，支持并发访问

### 1.2 架构原则
1. **前后端分离**：前端Vue 3，后端Spring Boot，通过RESTful API通信
2. **Agent与业务解耦**：Agent层通过API调用业务层，不直接访问数据库
3. **模块化设计**：功能模块独立，降低耦合度
4. **接口标准化**：统一的API设计规范和数据格式
5. **安全优先**：权限控制、数据加密、日志审计

### 2.2 架构说明

#### 用户层
- **学生浏览器**：学生通过Web界面与系统交互
- **辅导员浏览器**：辅导员通过Web界面管理学生事务
- **管理员浏览器**：管理员通过Web界面管理系统

#### 前端应用层
- **技术栈**：Vue 3 + Vite + Element Plus + Axios + Vue Router + Pinia
- **功能模块**：登录、AI聊天、任务管理、政策查询、数据看板
- **特点**：响应式设计，支持PC和移动端

#### 网关层
- **技术**：Nginx
- **功能**：反向代理、负载均衡、静态资源服务、SSL终结
- **配置**：前端静态文件服务，后端API代理

#### 后端服务层
- **技术栈**：Spring Boot 3.x + MyBatis-Plus
- **分层架构**：Controller → Service → Mapper → Database
- **功能**：业务逻辑处理、数据访问、API接口

#### Agent网关层
- **技术**：自定义AgentService
- **功能**：Agent能力抽象、Provider切换、Mock机制
- **特点**：支持FastGPT和Mock两种模式

#### Agent平台层
- **平台**：SF-FastGPT（外部平台）
- **功能**：LLM推理、知识库检索、Workflow执行、Tool Calling
- **特点**：作为外部服务调用，不集成到项目中

#### 数据存储层
- **MySQL**：业务数据存储（用户、学生、政策、任务等）
- **Redis**：缓存、会话管理、临时数据
- **FastGPT知识库**：政策文档向量化存储

## 五、数据库架构设计

### 5.1 数据库选型
- **主数据库**：MySQL 8.0
- **缓存数据库**：Redis 7.0（可选）
- **知识库**：SF-FastGPT向量数据库

### 5.2 数据库连接池
- **连接池**：HikariCP（Spring Boot默认）
- **最大连接数**：50
- **最小空闲连接**：10

### 6.2 复杂度路由设计

```
用户输入
  ↓
Intent/Complexity Router
  │
  ├── Simple (简单)
  │      ↓
  │    RAG问答
  │      ↓
  │    直接返回答案
  │
  ├── Complex (复杂)
  │      ↓
  │    RAG + Tools
  │      ↓
  │    调用工具获取信息
  │      ↓
  │    生成综合回答
  │
  └── Action (任务)
         ↓
      Workflow
         ↓
      多步骤执行
         ↓
      创建任务
         ↓
      发送通知
```

### 6.3 资格判断引擎

```
LLM提取条件
  ↓
规则引擎处理
  ↓
确定性判断
  ↓
LLM解释结果
```

**重要原则**：LLM负责理解和解释，规则引擎负责最终判断。

### 8.1 认证机制

```
用户登录
  ↓

  ↓
生成JWT Token
  ↓
返回Token给前端
  ↓
前端存储Token
  ↓
后续请求携带Token
  ↓
后端验证Token
  ↓
权限检查
```

#### JWT Token结构
```json
{
  "header": {

  },
  "payload": {

  }
```

### 8.2 权限控制

#### RBAC模型
```
用户 (User)
  │
  ├── 学生 (Student)
  │      权限：查看自己的信息、办理自己的事务
  │
  ├── 辅导员 (Counselor)
  │      权限：查看授权学生、审批申请
  │
  └── 管理员 (Admin)
         权限：所有权限
```

#### 权限注解
```java
@PreAuthorize("hasRole('STUDENT')")
public StudentVO getStudentProfile() {
    // 只能获取自己的信息
}

@PreAuthorize("hasRole('ADMIN')")
public List<StudentVO> getAllStudents() {
    // 管理员可以获取所有学生
}
```
